# 客户端协议与状态

本工程按原生 RFTG 的 `src/comm.h`、`comm.c`、`client.c`、`server.c`、`engine.c` 和各扩展网络模块实现，目标版本为 1.2.1。

TCP 帧为两个 big-endian int32（消息类型、含头部的总长度），后接 int32 或 NUL 结束的 UTF-8 字符串。帧长范围 8–32768。`server/protocol.mjs` 处理拆包、粘包与边界检查。登录字段为账号、密码、协议版本 `0.9.4`、功能版本 `1.2.1`。

Node 每个会话单独维护 TCP、解码缓冲、状态、未完成选择与恢复 token。浏览器只能提交命名的游戏操作，不开放任意 TCP 消息。恢复 token 保存在当前标签页的 sessionStorage，并按 WebSocket 网关 URL 分开保存；密码不写入本地存储或服务端文件。公共快照将未知手牌和牌库设计编号置为 -1。

## 状态帧

| 消息 | 处理 |
| --- | --- |
| 20–29 | 大厅房间、席位、加入/离开和开始 |
| 40 | 游戏参数、目标、玩家名、AI 标记、模式、Arc 1 掩码 |
| 41 | 玩家行动、目标进度、威望、VP 筹码、临时能力 |
| 42 | 物理卡牌位置、归属、阶段初始位置、货物、损伤及可选设计编号 |
| 43–44 | 目标、回合、VP 池、阶段和入侵快照 |
| 48 | 自己的席位编号；轮转时随后收到完整 meta |
| 51 | Orb v3：地图、卡片、队伍、神器和各玩家可见状态 |
| 52 | XCS v1：边境独立牌堆、候选、系统、征服和反击状态 |
| 70 | 游戏结束；得分来自此前的权威结算日志 |

普通物理牌的设计编号按卡牌 catalog 与扩展组合重建，服务器混淆未知卡片位置，客户端不能把这些占位位置当作公开身份。XCS 的动态物理牌由状态帧追加。Meta 也可能因其他人重连而重发，不能因此丢弃本人的未完成选择。

## 选择合同

请求 60：`pos, type, n, list[n], ns, special[ns], arg1, arg2, arg3`。

响应 60：`pos, type, rv, n, list[n], ns, special[ns]`。

`pos` 为选择日志中的 int 数量，不是回合号或帧序号。一个响应增加 `4+n+ns` 个日志元素。每个新选择以服务器位置为准；发送后马上关闭旧提示，避免重复提交。服务器的原 `verify_choice()` 未启用语义验证，本工程在网关验证类型、成员、多重性、成对能力、数量及支付；浏览器共用相同模块。

几个容易混淆的约定：

- ACTION 的输入数组是输出缓冲，响应必须包含两个行动，单行动用 `[action,-1]`。
- START 为两个手牌弃牌和一个起始世界。
- SETTLE 的普通能力是 `list[i]/special[i]` 配对；直接支付为 `[-99,...hand] / [-99]`。替代费用已支付时使用空数组确认。
- GOOD 中重复 world ID 代表该世界的多件货物。Orb 编号 328 起还可以代表神器货物。
- 入侵和 Orb 临时军力选择返回 1-based 索引，并保留完整候选数组。
- 边境世界选择使用独立牌堆的局部 ID 与 offer tag，不能当成主牌堆物理 ID。
- PREPARE 61 只是可选的原客户端预测优化。网关立即回复 phase，不生成选择、不增加日志位置；真实问题仍由服务器随后发出。忽略此帧会使无后续问题的玩家一直停留在 WAIT_OPTION。

JS 只计算交互所需的客户端检查，不执行权威游戏循环，不生成洗牌结果，不代替服务器结算。扩展快照保持服务器提供的隐私边界。


## 分离部署的浏览器传输

静态入口从自身域名加载 `client-config.json`、数据和 JS；`gatewayOrigin` 为空时使用同源地址，否则使用该 Origin 的 `/api/config` 和 `/ws`（HTTPS 自动对应 WSS）。Node 的 `PUBLIC_ORIGIN` 与 `ALLOWED_ORIGINS` 同时控制 API CORS 和 WebSocket Origin，按完整协议、主机和端口校验，不借助转发头推断授权。

生产环境由 Nginx 终止 TLS，只有 `/api/config`、`/healthz`、`/ws` 转发到内部 Node。动态域名上的静态路径 301 到 CDN 静态域名，Node 本身设置 `SERVE_STATIC=false`。跨域部署不改变 CHOOSE 格式、TCP 上游或服务器结算规则。配置与缓存约定见 [DEPLOYMENT.md](DEPLOYMENT.md)。
